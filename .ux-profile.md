# UX Profile

Generated by `setup-ui-ux-skills` on 15 November 2026. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** The site's own identity, shared with HOLD. Dark by default (`#0c141d` page, `#13212c` raised), light theme supported. Two accents only: mint (`--accent`, `#3fbf9a` dark / `#157a5e` light) and amber for the next step. No web fonts: system stacks through `--sans`, `--serif`, `--mono`. Use the CSS tokens in `src/styles/` (`--bg`, `--bg-raised`, `--ink`, `--ink-soft`, `--muted`, `--line`, `--accent`, `--accent-soft`, `--radius`); never invent a token.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations
- Nested scrollbars and icon bloat inside inputs
- Engineering detail on hub pages (release gates, pending tests, PR numbers): it belongs on the profile page

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4.5:1 for normal text, 3:1 for large text, in both themes. Non-text contrast (WCAG 1.4.11) of 3:1 applies where the boundary is what identifies the control: inputs, checkboxes, radios, selects. A button or filter identified by its label may keep a `--line` border (about 1.3:1 light, 1.4:1 dark); such a control must still show a visible focus ring
- **Touch / focus:** 44×44px targets on mobile, visible focus ring on every interactive element; status is never conveyed by color alone

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** French and English, American spelling in English. Plain promise first, product name second. One word per thing across a flow (the report is "rapport" everywhere). Every claim keeps its scope and limits; no certification language.

## Icon library

- **Library:** None
- **Package / path:** Text arrows only (`→` internal, `↗` external). New arrows go in an `aria-hidden` span; some older links still render them as raw text, to be fixed when those pages are edited
- **Notes:** No icon package is installed. Do not add one, and do not use emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon convention. Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
