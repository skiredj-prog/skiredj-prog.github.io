
# Lens Integration Audit

## Verdict
Keep the Lens.

## Correct role
The Lens should be:
- interpretive front-end
- simulation / scenario cockpit
- executive / pedagogical surface
- narrative synthesis layer

The Lens should not remain the semantic sovereign.

## Observed strengths
Across the uploaded Lens pages, the product surface already includes:
- dashboard
- prompt ingress
- real-time mode
- scenarios
- trace
- constitutional framing
- telemetry
- strategic-manifesto style output

## Immediate refit target
The Lens must consume governed upstream objects instead of carrying constitutional authority locally.

## Required rewiring
1. keep the Lens UI shell
2. remove app-local sovereignty over posture/compliance meaning
3. make the Lens consume:
   - canonical runtime object
   - validator output
   - policy decision
   - governance status
4. bind scenarios to the governed scenario pack
5. bind manifesto generation to canonical runtime outputs

## Final relationship
- Lens = cockpit
- Engine = diagnostic substrate
- Governance = enforcement world
