Three runs recorded during the frozen E1-A6 campaign: Llama 3.2 3B acting through HOLD, against a synthetic hotel provider. Every line below is read from the trace file named in the proof panel. Nothing is re-enacted.

  • Campaign: 33 runs with HOLD
  • 8 missions completed with proof
  • 0 violations recorded
  • Same model without HOLD: 66 violations

    Reading the ledger

    • Numbers on the left are positions in HOLD's hash-chained journal. Lines without a number come from the agent's own conversation.
    • I1: an equivalent effect is never sent twice. I4: arguments, envelope (the price ceiling) and the correction budget.
    • VERIFY checks the booking status, CONTACT_SUPPORT asks the provider's support, ASK_AUTHORITY sends a Decision Request. σ is how far a path is expected to restore certainty; τ* is the threshold set by the profile.

    Check it yourself

    The proof panel was computed from each trace with the replay tool in the repository. Run it on your machine:

    git clone https://github.com/skiredj-prog/hold
cd hold && pip install -e .
python -m hold.showcase bench/results/a6-c-3b/C-llama_llama3.2-3b_S9_r1.json
